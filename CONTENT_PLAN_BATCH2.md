## Production Workflow

### Phase 1: Write English Pillars (20 days)
- Research each topic (web search, Baymard, NNG, ecommerce sources)
- Write pillar (2000–3000 words)
- Write 4 child topics per pillar (~800 words each)
- Create images (1 pillar = 4–6 images, 1 child = 1–2 images)
- Total: 20 pillars + 80 children = 100 EN articles

### Phase 2: Translate to 8 Languages (parallel)
- EN → VI, FR, DE, ES, IT, PT, JP, ZH-CN
- Use translate-multi.workflow.js
- Total: 100 articles × 8 languages = 800 translated articles

### Phase 3: Commit & Deploy
- Git commit với message có TASK marker
- Push to main → Cloudflare auto-deploy
