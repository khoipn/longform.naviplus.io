## Working Process

For each image:

1. Read the target article section around the figure.
2. Write one concept with:
   - Section
   - Headline
   - Subtitle
   - Key visual
   - Callouts
   - Target filename
   - Alt
   - Title
   - Caption
3. Generate one standalone image with the built-in image tool.
4. Save the generated PNG from `~/.codex/generated_images` into the target WebP using:

   ```bash
   python3 scripts/save_latest_generated_image.py images/{article-slug}/{filename}.webp
   ```

5. Inspect dimensions/filesize:

   ```bash
   identify images/{article-slug}/{filename}.webp
   ```

6. If needed, update the article figure metadata, but most target files already have correct `alt`, `title`, and captions.
7. Run a build check when a batch is complete:

   ```bash
   bundle exec jekyll build
   ```
